# 📋 选题队列 — Episode Queue

> 所有选题按状态排列。**只有制片人可以修改 status 字段**，其他成员可以追加备注。

## 状态说明

| 状态 | 含义 |
|------|------|
| 💡 idea | 新选题，待制片人评估 |
| 🔍 researching | 调研员正在深挖话题 |
| ✍️ writing | 文案正在创作大纲和问题清单 |
| ✅ ready | 录前准备完成，等待录制 |
| 🎤 recorded | 已录制，文案正在处理录后物料 |
| 📢 published | 全流程完成 |
| 🗑️ dropped | 已放弃 |
