# 团队协作规则

## 通用规则

1. **工作目录规范** — 所有任务产出物必须放在指定工作目录下，不得在目录外创建文件
2. **日志规范** — 每次重要操作后写入活动日志，方便回溯和协作
3. **通知规范** — 关键节点（任务创建、提交、审查、异常）发送通知
4. **文件命名** — 使用有意义的文件名，避免 temp、test 等临时命名

## 质量标准

1. 所有交付物必须附带交付摘要日志
2. 代码类交付物需包含基本测试或验证说明
3. 文档类交付物需结构清晰、无明显错误

## 协作规范

1. 不要修改其他 Agent 正在执行的子任务
2. 遇到问题先查日志找已有方案，再尝试自己解决，最后才求助
3. 返工时必须针对审查意见逐项修复，不要遗漏
4. 每次自省笔记不要重复已有内容
