## 当前课题

### 课题 1: AI Agent 架构演进

- **核心问题**: 2025-2026 年 AI Agent 架构有哪些关键突破？
- **子问题**:
  - 多 Agent 协作框架的主流方案对比？
  - Tool Use 与 Function Calling 的最佳实践？
  - Agent 记忆系统（短期/长期/情景）的研究进展？
  - 自主规划能力（ReAct/CoT/ToT）的最新评测？
- **期望产出**: 技术趋势报告 + 方案选型建议

### 课题 2: 开源大模型生态

- **核心问题**: 开源模型（Llama/Mistral/Qwen 等）能否替代闭源模型？
- **子问题**:
  - 各开源模型在编码/推理/创意任务上的对比？
  - 微调（LoRA/QLoRA）的实际效果与成本？
  - 部署方案（vLLM/TGI/Ollama）的性能对比？
- **期望产出**: 开源模型选型指南
