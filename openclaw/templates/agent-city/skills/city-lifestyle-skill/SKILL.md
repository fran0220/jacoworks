## 文件协作系统

### 常用搜索关键词

| 场景 | 搜索词模板 |
|------|-----------|
| 餐厅推荐 | `亦庄 {品类} 推荐 {年份}` |

| 新店探索 | `亦庄 新店开业 折扣 {月份}` |

| 平台搜索 | `亦庄 {平台} {品类}` |
| 外卖搜索 | `亦庄 外卖 评分高 {品类}` |
| 赛事中心 | `北京智慧电竞赛事中心 附近 {品类}` |

### 搜索技巧

- 加上当前年份（如 `2026`）获取最新信息
- 结合平台名（`大众点评`、`美团`、`小红书`）提高信息质量
- 搜不到结果时扩大范围到 `亦庄开发区` 或 `南五环`
- 对比多个搜索结果交叉验证价格和营业状态

## 搜索工作流

```
1. read GOALS.md                              → 今日推荐方向
2. read agents/esports/output/schedule.md     → 今日有无赛事
3. web_search 亦庄 美食/优惠                   → 新鲜数据
4. 判断时段：
   - 11AM → 午餐推荐
   - 5PM  → 晚餐+夜生活，有赛事加赛后方案
5. write agents/lifestyle/output/              → 推荐内容
6. write agents/lifestyle/notes.md             → 工作日志
7. update STATUS.md「本地生活」部分
```

## 内容产出规范

### 推荐卡片格式

```markdown
### 🍜 {店名}

- **品类**：火锅 / 烧烤 / 日料 / …
- **人均**：¥{价格}
- **地址**：亦庄{具体地址}（距赛事中心约{X}分钟步行）
- **营业时间**：{HH:MM} - {HH:MM}
- **评分**：大众点评 {X.X} 分
- **推荐理由**：{1-2句，突出特色或适合场景}
- **优惠**：{团购/折扣/新客立减，标注截止日期}
- **适合**：赛后聚餐 / 深夜宵夜 / 小团队 / 大包间

> 💡 {一句实用探店提示}
```

### 优惠清单格式

```markdown
## 📢 亦庄优惠速报（{date}）

| 店名 | 优惠内容 | 原价→优惠价 | 截止日期 | 来源 |
|------|---------|------------|---------|------|
| XX店 | 新客立减20 | ¥80→¥60 | {日期} | 美团 |

> ⏰ 更新于 {date}，优惠以到店实际为准
```

### 组局方案格式

```markdown
## 🎮 赛事日组局方案 — {日期}

> 比赛: {队伍A} vs {队伍B} @ {时间}

### ⏰ 时间线
| 时间 | 安排 | 地点 | 预算 |
|------|------|------|------|
| 16:00 | 赛前聚餐 | {店名} | ¥{人均} |
| 17:00 | 观赛 | 赛事中心 / 直播 | — |
| 20:00 | 赛后庆功/安慰 | {店名} | ¥{人均} |

### 💰 人均总预算：¥{总计}
### 🎁 可用优惠：{优惠信息}
```

## 重要提醒

- **所有推荐必须基于 web_search 真实数据，不编造**
- 推荐必须包含价格、地址、营业时间，缺失的标注「待确认」
- 优惠信息必须标注来源和截止日期
- 超过 7 天未验证的信息标注「待确认」
- 先看 GOALS.md 了解今日方向
- 参考 esports/schedule.md 踩准赛事节奏
- 只写自己 agents/lifestyle/ 下的文件 + STATUS.md 生活部分
